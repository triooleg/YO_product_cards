# Changelog

## 1.1.0 - 2026-10-07

- Добавлен компактный SIZE-блок с существующим переключателем cm/in.
- Добавлены три настраиваемые услуги и диалог уменьшения четырех измерений до 4 cm.
- Итог покупки включает услуги после скидки на базовый товар; скидка вынесена в угол карточки.
- Валютный переключатель перенесен к покупке, синхронизируется между карточками и услугами.
- Добавлены состояние по product/feed ID, публичный API и события для будущей интеграции Checkout.
- Поддержана повторная инициализация и динамическая замена DOM.
- Исправлено сохранение настроек других вкладок, сохранены ссылки и data-атрибуты новой sale-кнопки.
- Добавлены Playwright/PHP-проверки и проверка извлеченных файлов ZIP.

## 1.0.2 - 2026-06-14

- Removed the bullet separator before prices in generated sale buttons.
- Added a packaging script that builds an update-safe WordPress ZIP with one top-level plugin folder.
- Documented archive verification and release rules.

## 1.0.1 - 2026-06-14

- Initial documented GitHub version of the plugin.

# Проверка 1.1.0 — 2026-10-07

Локально выполнены 14 Playwright-сценариев (Chromium): все пройдены. Проверены обычная и sale-карточки, услуги/суммы/снятие, ограничения уменьшений, отмена/повторное открытие, глобальная EUR/USD и cm/in, DOM-render, поздний ID, XML matching, снимки контракта, замена кнопки Checkout, ошибка валютного API и master switch.

Проверены desktop с тремя карточками, tablet и mobile 375/320 px. Нет горизонтальной прокрутки; popup помещается в viewport и прокручивается. Desktop/mobile снимки просмотрены визуально.

PHP: проверка синтаксиса и тест сохранения вкладок/цен услуг пройдены. JS: проверка синтаксиса обоих модулей и существующая проверка отсутствия bullet пройдены.

Установочный ZIP сохраняет прежний slug и главный файл; сборщик проверяет единственный корень, обязательные файлы, CRC и соответствие извлеченных файлов исходникам. Предыдущий основной ZIP сохраняется локальным timestamp-backup.

Ограничения проверки: WordPress/staging не развернут локально; полноценный заказ и оплата услуг не выполнялись. Публичная разметка сайта прочитана для аудита, но на сайте код не обновлен. Текущий Checkout получает базовую цену; платные услуги требуют следующего этапа серверной интеграции по `PERSONALIZATION.md`.

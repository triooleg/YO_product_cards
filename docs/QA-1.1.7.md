# Проверка 1.1.7 - 2026-10-08

Рост для заголовка SIZE читается из ближайшего data-tag у карточки или ее контейнера: Height-145-150. Неположительные и обратные диапазоны не отображаются. Другие теги, например figure-skating, не заменяются догадкой из заголовка. Иконка person-standing из существующей библиотеки Lucide отображается синим, как линейка; текст Height отсутствует в видимой строке, доступное имя присутствует.

Общий форматтер переключает рост между cm/in без изменения исходного диапазона. Цены, услуги, ограничения подгонки и видео не изменены. ZIP сохраняет прежнюю папку и основной PHP-файл плагина.

19 Playwright-сценариев пройдены. Проверены приоритет метки фильтра перед отличающимся заголовком товара, конвертация, отсутствие роста для других тегов и дубликатов при переинициализации. На 1440/820/375/320 px проверены заголовок без переполнения, четыре мерки, кнопки и модальное окно.

Read-only preview действующей темы с локальными ассетами проверяет реальную метку родительского контейнера, компоновку cm/in, Play и загрузку исходного видео. Все запросы кроме GET заблокированы. Установка плагина на сайт и отправка заказов не выполнялись. PHP/JS и содержимое ZIP проверяются перед публикацией.

# Проверка 1.1.8 - 2026-10-08

Для роста используется только первый элемент data-tag, разделенного запятыми, с удалением краевых пробелов. Поддержаны Height 170-175 и Height-170-175, регистр не важен, в диапазоне допустимы дефис и тире. Остальные теги игнорируются. Если первый тег не содержит корректный положительный диапазон роста, блок роста не отображается; поиск по последующим тегам или заголовку товара не выполняется.

20 Playwright-сценариев проверяют текущую карточку. Новый сценарий включает семь вариантов: пробел после Height, несколько диапазонов роста, пробелы/регистр/тире, первый тег figure skating, нулевой рост, обратный диапазон и пустое значение. Существующие cm/in, адаптивность, Play, валюта и услуги сохранены.

Read-only preview действующей темы использует локальные ассеты; установка на сайт и отправка заказов не выполняются. ZIP сохраняет прежнее имя папки и основной PHP-файл для обновления существующего плагина, предыдущий архив сохраняется.

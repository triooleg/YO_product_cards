# Агенты проекта

Эта папка содержит роли для дальнейшей разработки плагина `YOleotard Product Card Enhancer`.

Перед задачей агент должен:

1. прочитать `README.md`;
2. прочитать `ORCHESTRATOR.md`;
3. прочитать свой файл роли;
4. проверить актуальный `git status -sb`;
5. после работы оставить понятный список локальных и живых проверок.

Роли:

- `logic-architect.md` - архитектура и границы изменений;
- `wordpress-plugin-engineer.md` - PHP и WordPress admin;
- `frontend-dom-engineer.md` - браузерная логика карточек;
- `qa-release-engineer.md` - проверки, релизы и GitHub.
